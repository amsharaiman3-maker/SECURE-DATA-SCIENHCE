Secure Data Science Architecture

                  
Compliance, Zero-Trust principles, and PII protection breakdown

                

              

              

                

                  

                    
🛡️

                    

                      
Zero-Knowledge Client Processing

                      
Uploaded CSV files are read via the HTML5 FileReader API into browser heap memory only. No sockets, fetch endpoints, or third-party analytic telemetry are invoked.

                    

                  


                  

                    
🎭

                    

                      
Automated PII Masking & Pseudonymization

                      
Names, phone numbers, student IDs, and emails undergo immediate regex masking (e.g., Aarav Sharma → A**** S*****; +91-9876543210 → +91-******3210).

                    

                  


                  

                    
🔑

                    

                      
Native Web Crypto API Standard

                      
Keys are synthesized using browser-native window.crypto.subtle primitives without external NPM libraries, guaranteeing reproducible, audit-friendly cryptography.

                    

                  


                  

                    
⚖️

                    

                      
FERPA & GDPR Alignment

                      
Fulfills the Principle of Data Minimization (Article 5(1)(c) GDPR) and Education Record Redaction (FERPA 34 CFR Part 99).
